ПОЯСНЕНИЕ К САЙТУ-ПОРТФОЛИО
================================

Этот файл объясняет два файла сайта:
1. index.html — содержание и порядок элементов страницы.
2. style.css — цвета, размеры, расположение и внешний вид элементов.

КАК КОРОТКО РАССКАЗАТЬ О ПРОЕКТЕ
--------------------------------

«Я сделал одностраничное портфолио. HTML задаёт структуру: шапку,
разделы, текст, фотографии, карточки проектов и контакты. CSS задаёт
оформление и расположение. Навигация ведёт к разделам этой же страницы.
В проекте нет JavaScript. Кнопка “Русский” оставлена отключённой».

Важно: кнопка «Русский» не переключает языки. Она помечена словом
disabled и нужна только как элемент оформления.


ЧАСТЬ 1. INDEX.HTML — СТРУКТУРА СТРАНИЦЫ
========================================

1. Начало документа и настройки
--------------------------------

<!DOCTYPE html>
Говорит браузеру, что документ использует современный HTML.

<html lang="ru">
Начало HTML-страницы. Атрибут lang="ru" указывает язык страницы —
русский. Это полезно браузеру, поисковикам и программам чтения с экрана.

<head>
Начало невидимой части с настройками страницы.

<meta charset="UTF-8">
Выбирает кодировку, которая позволяет правильно показывать русские буквы.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
Помогает браузеру правильно выставлять ширину страницы на разных экранах.
width=device-width означает ширину окна устройства, а initial-scale=1.0 —
обычный масштаб при открытии.

<meta name="description" content="...">
Краткое описание страницы, которое может использовать поисковик.

<meta name="theme-color" content="#e8ff8c">
Задаёт цвет темы браузера на устройствах, которые поддерживают эту настройку.

<title>Нурэль — веб-разработчик</title>
Название страницы. Оно показывается, например, на вкладке браузера.

<link rel="stylesheet" href="style.css">
Подключает отдельный файл оформления style.css. href указывает путь к файлу.
Так браузер знает, какие правила CSS применить к HTML.

</head>
Закрывает настройки документа.

<body>
Начинает видимую часть сайта. Основное содержимое страницы находится здесь.


2. Шапка и навигация
--------------------

<header class="site-header" id="top">
Семантический элемент шапки сайта. class="site-header" связывает блок
с CSS-правилом .site-header. id="top" даёт этому месту уникальное имя,
на которое можно перейти по ссылке #top.

<a class="logo" href="#top" aria-label="Нурэль — наверх">
Ссылка с логотипом. href="#top" возвращает к началу страницы.
aria-label даёт ссылке понятное доступное название для экранного диктора.

<span class="logo-mark">Н</span>
Маленький элемент с буквой «Н». Класс logo-mark нужен CSS, чтобы сделать
из буквы цветной квадратик.

<span>Нурэль<span class="logo-dot">.</span></span>
Показывает имя и точку. Вложенный span с классом logo-dot позволяет отдельно
покрасить точку.

<nav class="main-nav" aria-label="Основная навигация">
Семантический блок главного меню. Внутри находятся ссылки на разделы сайта.
aria-label объясняет, что это основная навигация.

Ссылки вида <a href="#about">Обо мне</a>
Переходят к элементу, у которого есть id="about". Остальные пункты меню
так же ведут к #process, #projects и #contact.

<button class="language-button" type="button" disabled ...>
Создаёт кнопку «Русский». type="button" означает, что это обычная кнопка,
а не кнопка отправки формы. disabled отключает нажатие. aria-label описывает
назначение для вспомогательных технологий.

Закрывающие теги </a>, </nav>, </header>
Закрывают ссылку, меню и шапку. В HTML вложенные элементы закрывают в обратном
порядке: сначала тот, который открылся последним.

ЧАСТЬ 2. STYLE.CSS — ВНЕШНИЙ ВИД САЙТА
======================================

КАК ЧИТАТЬ CSS-ПРАВИЛО
----------------------

Пример:

.hero {
    background: lime;
}

.hero — селектор: он выбирает элемент, у которого в HTML написано
class="hero". Точка перед словом означает, что ищется именно класс.

Фигурные скобки содержат правила оформления.
background — свойство, то есть что настраиваем.
lime — значение, то есть какое оформление применяем.
Точка с запятой завершает одну настройку.

ОБЩИЕ ПОНЯТИЯ И СВОЙСТВА
------------------------

:root — специальный верхний элемент документа. Здесь объявлены общие цвета:
--lime, --ink, --muted и --dark. Это CSS-переменные. Чтобы использовать цвет,
пишут, например, var(--lime).

font-family — шрифт и запасные шрифты, если основной отсутствует.
color — цвет текста.
background — цвет или изображение фона.
font-size — размер текста.
font-weight — толщина букв; 700 и 900 означают жирное начертание.
line-height — высота строки.
letter-spacing — расстояние между буквами.
text-align — выравнивание текста.
text-transform — преобразование регистра. uppercase отображает буквы
заглавными, не меняя исходный текст.
text-shadow — тень у букв.
text-rendering — настройка отображения текста браузером.
font-synthesis — разрешает или запрещает браузеру самостоятельно создавать
варианты шрифта, которых нет в исходном шрифте.
font — сокращённая запись настроек шрифта. Например, в правилах терминала
одной строкой задаются размер, высота строки и моноширинный шрифт.

width — ширина.
height — высота.
min-width / min-height — минимальная ширина или высота.
max-width — максимальная ширина.
aspect-ratio — соотношение ширины и высоты блока.
margin — внешний отступ вокруг блока.
padding — внутренний отступ от края блока к содержимому.
gap — промежуток между элементами flex или grid.

border — рамка.
border-radius — округление углов.
box-shadow — тень.
opacity — прозрачность; 1 — непрозрачно, 0 — невидимо.
overflow: hidden — обрезает содержимое, выходящее за границу блока.
object-fit: cover — заполняет рамку изображением, обрезая лишнее без
искажения пропорций.
object-position — выбирает, какую часть изображения показывать после обрезки.

display: flex — раскладывает элементы в линию или колонку и помогает
выравнивать их.
display: grid — раскладывает элементы по строкам и колонкам.
position: relative — оставляет элемент на обычном месте, но позволяет
позиционировать его внутренние элементы относительно него.
position: absolute — размещает элемент по координатам внутри ближайшего
родителя с position: relative.
position: fixed — закрепляет элемент относительно окна браузера.

top, right, bottom, left — расстояния от соответствующих краёв для
позиционируемых элементов.
z-index — порядок наложения элементов: большее число располагается выше.
align-items — выравнивание элементов поперёк направления flex или grid.
justify-content — распределение элементов вдоль flex-оси.
justify-self — выравнивание одного элемента в ячейке grid.
place-items / place-content — сокращённые способы выравнивать содержимое
в сетке.
grid-template-columns — задаёт колонки сетки.
grid-template-columns: repeat(3, 1fr) значит три равные колонки.
fr — доля доступного свободного места.
flex-wrap: wrap — разрешает элементам переходить на следующую строку.

transition — плавность изменений.
:hover — состояние элемента, когда на него наведена мышь.
transform: translateY(...) — перемещает элемент вверх или вниз.
transform: rotate(...) — поворачивает элемент.
linear-gradient(...) — создаёт плавный переход между цветами.
clamp(минимум, предпочитаемый размер, максимум) — выбирает размер,
не выходящий за указанные границы.
min(...) — выбирает меньшее из переданных значений.
max(...) — выбирает большее из переданных значений.
calc(...) — позволяет вычислять значение, например ширину за вычетом отступов.
rgba(...) — задаёт цвет по каналам красный, зелёный, синий и прозрачность.
% — процент от размера родительского блока.
px — пиксели.
vw — процент от ширины окна браузера.
1fr — одна часть доступного места в сетке.


1. Начальные общие правила
--------------------------

:root
Задаёт шрифт, основные цвета текста и фона, плавную прокрутку и цветовые
переменные для повторного использования в других CSS-правилах.

*
Звёздочка выбирает абсолютно все элементы. box-sizing: border-box упрощает
расчёт размера: рамка и внутренние отступы входят в заданную ширину.

body
Убирает стандартный внешний отступ браузера, чтобы страница начиналась
ровно у края окна.

img
display: block убирает маленький зазор под картинкой, а max-width: 100%
не даёт изображению стать шире родительского контейнера.

a
Наследует цвет от родительского текста и отключает стандартное подчёркивание.

button
font: inherit заставляет кнопку использовать тот же шрифт, что и страница.


2. Шапка и меню
---------------

.site-header
Размещает шапку сверху страницы. display: flex выстраивает логотип,
навигацию и кнопку в один ряд. space-between раздвигает их, а center
выравнивает по вертикали. padding создаёт боковые отступы. z-index
поднимает шапку над другими элементами.

.logo
Выстраивает значок и имя рядом, задаёт расстояние, размер и жирность текста.

.logo-mark
Создаёт квадратный значок. grid и place-items центрируют букву.
border-radius округляет углы, background и color задают его цвета.

.logo-dot
Меняет цвет точки после имени.

.main-nav
Выстраивает пункты меню в ряд и задаёт промежутки между ними.

.main-nav a, .text-link, .contact-links a, .back-to-top
Через запятые перечислены несколько типов ссылок. Для всех включён плавный
переход прозрачности при наведении.

Селекторы с :hover
При наведении мышью делают перечисленные ссылки слегка прозрачными.

.language-button
Оформляет отключённую кнопку «Русский»: ширина, рамка, скругление, отступы
и шрифт. disabled в HTML, а не CSS, действительно запрещает нажатие.


3. Первый экран и фотография
----------------------------

.hero
Создаёт большой первый экран, размещает содержимое по центру, задаёт светлый
градиент и отступы. overflow: hidden обрезает украшения, вышедшие за края.

.hero-inner
Создаёт сетку из двух колонок: текста и фотографии. Колонки имеют пропорции
1.1 к 0.9. max-width не даёт содержимому стать слишком широким. margin: 0 auto
центрирует контейнер.

.hero-copy
Ограничивает ширину текста.

.eyebrow, .section-label
Общие правила для маленьких подписей над заголовками: выравнивание,

8. Правила для экранов разной ширины
------------------------------------

@media (max-width: 760px)
Это группа CSS-правил, которая действует, когда ширина окна 760 пикселей
или меньше. Она уменьшает шапку, размеры текста и промежутки. Сетка этапов
меняется с четырёх колонок на две.

@media (max-width: 540px)
Дополнительные правила для очень узких экранов. Меняются боковые отступы,
первый экран становится одной колонкой, карточка «Обо мне» перестраивается
вертикально, а проекты показываются по одной карточке в строке.

Внутри этих блоков часто встречаются те же свойства и селекторы, что и выше.
Это не дубликат ошибки: CSS использует новые значения только при указанной
ширине окна, а на широком экране остаются основные правила.


ПОНЯТИЯ, КОТОРЫЕ МОЖНО ОБЪЯСНИТЬ УЧИТЕЛЮ
=======================================

HTML — язык разметки. Он задаёт структуру и содержание страницы.
CSS — язык стилей. Он задаёт оформление и расположение.
Тег — запись в угловых скобках, например <p> или <section>.
Атрибут — дополнительная настройка тега, например href, class или id.
Класс — имя для группы элементов; в HTML пишется class="hero",
а в CSS выбирается точкой: .hero.
ID — уникальное имя элемента; в ссылке на него ставят # перед именем.
Селектор — часть CSS, которая выбирает элементы для оформления.
Flex — способ расположить элементы в линию и выровнять их.
Grid — способ разложить элементы по сетке строк и колонок.
Адаптивность — изменение расположения и размеров под ширину экрана.

Если спросят, почему иллюстрации похожи на код:
«Это только декоративная картинка, сделанная разметкой и CSS. Она не запускает
генератор. Рабочие проекты открываются по ссылкам на GitHub».

Если забудешь конкретное CSS-свойство, можно ответить:
«Это настройка оформления. HTML задаёт сам элемент, а это CSS-правило
определяет, как этот элемент выглядит и где он расположен».
